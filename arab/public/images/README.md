# Images

Place licensed photography here. Do not add unlicensed stock photos of people.

## Hero

- `hero-arab.jpg` — full-bleed hero. The hero `<img>` hides itself if this file is missing.
- Preferred subjects: people in modest traditional dress (thobe, abaya, kandura), modern Gulf cities (Dubai, Doha), or abstract blockchain visuals.
- Keep the first viewport brand-first: photography sits behind type, not in an inset card.

## Patterns (committed)

- `pattern-geometry.svg` — Islamic geometry tile.
- `pattern-mashrabiya.svg` — mashrabiya lattice.
- `pattern-calligraphy.svg` — decorative arabesque / calligraphy ornament (no Qur’anic text).
- `pattern-blockchain.svg` — abstract node/block network.

## Photography brief

Allowed: modest traditional clothing, Gulf skylines, geometric interiors, abstract chain/network art.

Forbidden: pigs, alcohol, revealing clothing, idols or symbols that contradict Islam, religious scripture used as decoration.

Keep this directory in git even when JPGs are absent.
