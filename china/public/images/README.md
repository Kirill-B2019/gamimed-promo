# Images

Place licensed photography here. Do not add unlicensed stock photos of people.

## Hero

- `hero-china.jpg` — full-bleed hero (Shanghai / Shenzhen inspired skyline). The hero `<img>` hides itself if this file is missing.
- Preferred subjects: modern cities (Shanghai, Shenzhen), technological abstractions, geometric dragon/phoenix luck motifs.
- Keep the first viewport brand-first: photography sits behind type, not in an inset card.

## Patterns (committed)

- `pattern-cloud.svg` — traditional cloud / geometric tile.
- `pattern-phoenix.svg` — abstract phoenix luck seal.
- `pattern-dragon.svg` — abstract dragon luck seal.
- `pattern-tech.svg` — hexagonal tech grid.
- `pattern-lattice.svg` — circular lattice / geometric window.
- `wechat-qr.svg` — placeholder QR until the production WeChat asset is provided.

## Photography brief

Allowed: Shanghai / Shenzhen skylines, circuit and network abstractions, stylized dragon or phoenix (luck).

Forbidden: politically sensitive imagery, maps with incorrect borders, prominent use of the number 4 as a lucky or marketing count (tetraphobia). Do not add PRC administrative maps.

Keep this directory in git even when JPGs are absent.
